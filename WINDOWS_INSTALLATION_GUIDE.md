## 🌟 3 Easy Methods to Run Xer0byte on Windows PC / Laptop

Whether you are using **Windows 11**, **Windows 10**, or **Windows 7/8**, you can run and use Xer0byte seamlessly on your PC.

---

### 🚀 Method 1: Windows 11 Native (Windows Subsystem for Android - WSA)
*Recommended for Windows 11 users — runs like an official native Windows desktop program!*

1. **Download Xer0byte.apk**:
   - Download **[Xer0byte.apk](./Xer0byte.apk?raw=true)** (23 MB) to your Windows PC.
2. **Install WSA / WSA-Pacman**:
   - If Windows Subsystem for Android is enabled on your Windows 11:
   - Double-click `Xer0byte.apk` (or right-click -> Open with **WSA-Pacman**).
   - Click **Install**.
3. **Launch from Windows Start Menu**:
   - Xer0byte will appear in your **Windows Start Menu** and **Taskbar** with its official logo!
   - It supports full keyboard typing, mouse navigation, and desktop window resizing.

## ⚡ How to Chat Between Windows PC and Android Phones (100% Offline)

1. **Turn on Bluetooth on Windows**:
   - Go to Windows **Settings** ➡️ **Bluetooth & devices** ➡️ turn Bluetooth **ON**.
2. **Turn on Bluetooth on Android Phone**:
   - Swipe down from top on your phone and enable Bluetooth.
3. **Pair the Devices**:
   - Pair your Windows PC and your Android phone once in Windows Bluetooth settings.
4. **Launch Xer0byte on Both**:
   - On Windows: Open Xer0byte.
   - On Android: Open Xer0byte.
   - Both devices will immediately show the **🟢 Glowing Green Dot** and **ONLINE** status!
5. **Start Chatting**:
   - Type messages from your Windows PC physical keyboard.
   - Send voice notes, documents, and pictures with **Zero Internet**!
