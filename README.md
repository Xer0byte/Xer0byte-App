## 🚀 100% Offline — No Internet Required

**Xer0byte** is a decentralized offline messaging application that enables direct, real-time phone-to-phone communication using Bluetooth RFCOMM sockets. It requires **zero cellular data, zero SIM card, and zero Wi-Fi connection**.

---

## 📱 How to Download & Install on Your Phone via GitHub

Whenever this repository is pushed to GitHub, **GitHub Actions automatically builds the APK** and publishes it with a direct download link!

### Method 1: Download from GitHub Releases (Recommended)
1. Go to your GitHub repository page.
2. Click on the **"Releases"** section on the right side (or visit `https://github.com/<your-username>/<repo>/releases`).
3. Tap on the latest release and click **`Xer0byte-Bluetooth-Messenger.apk`** to download it directly to your phone!
4. Open the downloaded file and tap **Install** *(allow "Install from Unknown Sources" if prompted)*.

### Method 2: Download from GitHub Actions Tab
1. Open the **"Actions"** tab at the top of your GitHub repository.
2. Click on the latest workflow run: **"Build & Release Xer0byte APK"**.
3. Scroll down to the **"Artifacts"** section at the bottom.
4. Click **`Xer0byte-Android-APK`** to download the ready-to-install package.

## ⚡ How to Connect & Chat (Phone to Phone)

1. **Install Xer0byte** on two or more Android devices.
2. Turn on **Bluetooth** on all devices.
3. On **Phone 1**:
   - Open **Xer0byte**.
   - Tap the **Bluetooth icon** in the top bar to open **Bluetooth Center**.
   - Tap **"Make Discoverable"**.
4. On **Phone 2**:
   - Tap **"Scan Nearby"**.
   - Tap Phone 1 in the list to connect.
5. **🟢 Green Dot Indicator**:
   - Both devices will immediately show a bright green dot (`🟢`) and **ONLINE** status!
6. Start exchanging real-time offline messages, voice audio notes, photos, documents, and interactive calls!

## 🌟 Key Features

- **WhatsApp Look & Feel**: 4 bottom tabs (**Chats**, **Updates/Status**, **Communities**, **Calls**).
- **Multi-Peer Mesh**: Connect multiple phones at the same time to create a local offline peer-to-peer network.
- **Voice Notes & Waveforms**: Record and play audio messages offline with visual waveform representation.
- **7-Item Attachment Menu**: Documents, photos, audio clips, live locations, contact cards, and polls.
- **Local Persistence**: Powered by SQLite Room database to keep conversations saved offline across app restarts.
- **Single-Device Test Mode**: Tap *"Connect to Ghaznain Ahmad (Xer0byte Companion)"* in Bluetooth Center to test chat replies even on a single phone or emulator.
